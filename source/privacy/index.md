# 网站隐私政策

欢迎您访问本网站（以下简称“本网站”）。本网站由 **AresDown** 个人开发并运营。  
我非常重视您的隐私与数据安全，本隐私政策将向您说明在您访问和使用本网站时，我如何收集、使用、存储和保护您的信息。

请您在继续使用本网站前，务必仔细阅读并充分理解本隐私政策。一旦您继续访问或使用本网站，即视为您已阅读、理解并同意本政策的全部内容。

如您对本政策有任何疑问，可通过邮箱 **dawn@aresdev.qzz.io** 与我联系。

## **本隐私政策将帮助您了解：**

1. 我如何收集和使用您的个人信息  
2. 我如何存储和保护您的个人信息  
3. 我如何共享、转让和公开披露您的个人信息  
4. 我如何使用 Cookie 和其他追踪技术

6. 本隐私政策的更新方式

## **一、我如何收集和使用您的个人信息**

本网站为个人博客，不提供注册、登录等账号功能，也不会主动收集可识别您身份的个人信息。

但在您访问本网站时，可能会自动收集以下信息，用于网站运行、安全和统计分析：

### **1. 服务器日志（由 GitHub Pages / Vercel 自动生成）**

由于本网站托管在 **GitHub Pages** 和/或 **Vercel**，这些平台可能会自动记录：

- IP 地址  
- 浏览器类型与版本  
- 访问时间  
- 请求的页面路径  
- 引荐来源（Referrer）  
- 设备信息  
- 访问状态（如 200/404）  

这些日志由 GitHub / Vercel 根据其隐私政策处理，我本人无法访问、下载或用于识别您的身份。

相关隐私政策：

- GitHub Privacy Statement: https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement  
- Vercel Privacy Policy: https://vercel.com/legal/privacy-policy  

### **2. 第三方服务可能收集的信息**

如果您使用了以下功能（视你博客实际情况而定）：

- 评论系统（如 Twikoo / Waline / Giscus）  
- 网站统计（如 Umami / 百度统计 / Google Analytics）  
- CDN 加速（如 Cloudflare）  
- 第三方嵌入内容（如 YouTube、Bilibili、GitHub 卡片）

这些服务可能会收集：

- IP 地址  
- 浏览器信息  
- Cookie  
- 页面访问行为  

这些数据由第三方根据其隐私政策处理，我不会直接存储或使用这些信息。

### **3. 您主动提供的信息**

如果您通过邮箱或反馈方式联系我，我可能会接收到：

- 您的邮箱地址  
- 您主动提供的内容  

这些信息仅用于回复您的咨询，不会用于其他用途。

## **二、我如何存储和保护您的个人信息**

本网站本身不存储任何可识别个人身份的信息。

第三方平台（如 GitHub / Vercel / 评论系统）可能会存储必要的技术性数据，它们均采用行业标准的安全措施保护数据安全。

我不会：

- 主动收集敏感信息  
- 将您的信息用于商业用途  
- 将您的信息出售给任何第三方  

---

## **三、我如何共享、转让、公开披露您的个人信息**

我不会与任何第三方共享、出售或转让您的个人信息。

但在以下情形中，可能无需事先征得您的同意：

1. 与国家安全、国防安全直接相关  
2. 与犯罪侦查、起诉、审判等直接相关  
3. 出于维护您或他人重大合法权益  
4. 您自行公开的信息  
5. 从合法公开渠道收集的信息  
6. 为履行法律法规义务  
7. 为保障网站安全运行所必需  

---

## **四、我如何使用 Cookie 和其他追踪技术**

本网站可能使用 Cookie 来实现以下功能：

- 记录深色模式 / 浅色模式偏好  
- 保存语言偏好  
- 评论系统登录状态（如使用第三方评论）  
- 网站访问统计（如启用统计工具）  

Cookie 不包含可识别您身份的信息。

您可以在浏览器中清除或禁用 Cookie，但可能会影响部分功能体验。

## **五、我如何处理未成年人的个人信息**

本网站主要面向成人用户，不提供注册功能，也不会主动收集未成年人的信息。

如您是未成年人的监护人，并认为本网站可能收集了未成年人的信息，请通过邮箱与我联系，我会尽快处理。

我可能会根据网站功能变化或法律要求更新本隐私政策。更新后的政策将在本页面公布，并自公布之日起生效。

如更新内容涉及重大变更，我会在网站显著位置提示。
