## Hexo 主题选择

Hexo 拥有非常丰富的主题生态，不同主题在设计风格、功能特性和扩展能力上各有侧重。选择一个适合自己的主题，能够让博客在视觉体验和使用体验上都更加出色。下面说一下我在社区中找到并选择的主题。

### 1. Next —— 经典稳定的极简主题

<a href="https://github.com/next-theme/hexo-theme-next" style="display: inline-flex; align-items: center; gap: 8px;">
  <img src="https://avatars.githubusercontent.com/u/63177289?s=48&v=4" alt="" width="48" height="48">
  <span>hexo-theme-next</span>
</a>

Next 是 Hexo 社区最经典的主题之一，以简洁、稳重、易用著称。
{% imgf theme-next.webp next主题%}
极简风格，阅读体验优秀,配置简单，文档完善,并支持多种布局与配色，插件生态成熟

[doc文档](https://theme-next.js.org/)

### 2. Butterfly —— 功能丰富的卡片风主题

<a href="https://github.com/jerryc127/hexo-theme-butterfly" style="display: inline-flex; align-items: center; gap: 8px;">
  <img src="https://avatars.githubusercontent.com/u/16351105?s=48&v=4" alt="" width="48" height="48">
  <span>hexo-theme-butterfly</span>
</a>

Butterfly 是近年来最受欢迎的 Hexo 主题之一，拥有现代化的卡片布局和大量扩展功能。
{% imgf hexo-butterfly.webp butterfly主题%}
卡片式 UI，视觉效果强，支持 Pjax、懒加载、动画等现代特性，自定义能力强，插件兼容性好

[doc文档](https://butterfly.js.org/)

### 3. Icarus —— 清爽现代的多布局主题

<a href="https://github.com/ppoffice/hexo-theme-icarus" style="display: inline-flex; align-items: center; gap: 8px;">
  <img src="https://avatars.githubusercontent.com/u/8849362?s=48&v=4" alt="" width="48" height="48">
  <span>hexo-theme-icarus</span>
</a>

Icarus 以清爽、现代、结构清晰著称，适合内容较多的博客。
{% imgf hexo-icarus.webp icarus主题%}
多种布局可选，支持丰富的组件（图库、图表、评论等），性能优秀，文档清晰

[doc文档](hhttps://ppoffice.github.io/hexo-theme-icarus/)

### 4. anzhiyu —— 现代化、精致、可定制性极强的主题（重点推荐）

<a href="https://github.com/anzhiyu-c/hexo-theme-anzhiyu" style="display: inline-flex; align-items: center; gap: 8px;">
  <img src="https://avatars.githubusercontent.com/u/73864136?s=48&v=4" alt="" width="48" height="48">
  <span>hexo-theme-anzhiyu</span>
</a>

在众多 Hexo 主题中，anzhiyu（安知鱼） 是一款非常突出的主题。它基于 Butterfly 深度优化，在视觉设计、交互体验和功能扩展上都做了大量增强，是目前 Hexo 生态中最具现代感和可玩性的主题之一。
{% imgf hexo-anzhiyu.webp anzhiyu主题%}
**主题亮点**

- 现代化 UI
- 动态背景
- 卡片式布局
- 流畅动画

**多种配色方案：整体视觉效果年轻、灵动、细节丰富。**
**功能极其全面**

- 深色模式
- Pjax 无刷新切换
- 图片懒加载
- 音乐播放器
- 自定义首页模块
- 文章封面图
- 评论系统（Twikoo / Waline 等）
- 站点统计、搜索、标签页等功能一应俱全

**自定义能力强：几乎所有模块都可以自由开关、调整、替换，适合喜欢打造个性化博客的用户。**
**维护活跃、文档完善：主题作者更新频率高，文档清晰，社区活跃，遇到问题也容易找到解决方案。**

[doc文档](https://docs.anheyu.com/)
