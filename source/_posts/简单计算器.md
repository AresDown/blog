## 开始之前

>在我们使用c语言编写计算器前我们需要先确认需要写哪些内容，由于c语言是面向过程的语言，若不使用GTK+、Qt、WinAPI等三方库提供的创建窗口功能，只能在控制台输出。
那么在控制台上输出，为了更加美观，我们需要添加一个显示菜单，可以使用`printf`函数来显示，我们需要在使用`#include<stdio.h>`基础上使用`#include<conio.h>`这个库。

## 变量定义

>我们需要设置3个双精度`double`变量分别表示2个数和1个答案,定义一个`char`字符变量`op`用于输入`+ - * /`运算,再定义一个整形`int`变量`i`来确认用户输入的字符数量(后续介绍)

```bash
double num1, num2, answer = 0;
char op;
int i;  //定义一个变量用于存储scanf函数的返回值
```

## 菜单创建

>下面我们开始写计算器的菜单：菜单可以使用多个`printf`函数输出

```bash
void menu()  //定义输出欢迎界面函数
{
	printf("\n");
	printf("*********************************\n");
	printf("* 欢迎使用简单计算器！           *\n");
	printf("* 本程序可以进行加、减、乘、除    *\n");
	printf("* 四种基本运算。                 *\n");
	printf("* 输入数据时请注意格式，          *\n");
	printf("* 可以使用退格键删除错误输入。    *\n");
	printf("*********************************\n");
	printf("\n");
}
```

## 核心函数`answer_1()`

>创建完菜单后我们需要写一个主循环体用于连续计算，这个自定义函数需要包含退出条件和清零条件；退出条件我们可以使用ASCII码中esc键的数值来写退出条件，清零条件我们可以指定一个键盘的字母来实现清零操作，具体写法如下：

```bash
double answer_1()  //定义计算函数
{
	while (1)
	{
		printf("请输入两个数字和一个运算符（+、-、*、/):\n");
		printf("请输入你要计算的表达式，例如:2+3\n");
		printf("按回车键结束输入,按ESC键退出程序,按C键清零\n");
			char f = getch();  //获取用户输入的字符
			if (f == 27)  //esc退出程序
			{
				printf("\n你已退出程序。\n");
				break;
			}
			if (f == 'c' || f == 'C')
			{
				printf("\n你已清零本次计算。\n");
				continue;
			}
		i = scanf("%lf %c %lf", &num1, &op, &num2);  //调用scanf函数并赋值给i
		while (getchar() != 10);  //清除用户输入后的缓存
		{
			if (i == 0) //判断i是否为0
			{
				printf("错误：无效的输入！\n");  //输出错误信息
				continue;  
			}
			if (i == 2)
			{
				printf("\n错误:无法计算表达式\n"); //输出错误信息
				continue;
			}
			if (i == 3)
			{
				double ans();
				answer = ans();
				printf("\n计算结果为:%.2lf\n", answer);
			}
			if (i == 4) 
			{
			    printf("\n你已清零本次计算。\n");  //输出错误信息
				continue;
			}
		}
	}
	return 0;
}
```

>我们需要使用`char f = getch();`这个来获取用户输入的数据并判断特殊情况(比如清零键`C`和退出键`esc`)而下面定义的`i = scanf("%lf %c %lf", &num1, &op, &num2);`这个部分就是用于判断用户输入的字符情况的，共四种情况：

- 第一种是什么都不输入的情况;
- 第二种是只输入了一个num1和op情况(一个数字和符号);
- 第三种是输入了2个数字和一个计算符号的情况(正常计算情况)；
- 最后一种是在第三种情况的基础上输入了特殊定义的情况(清零或者退出)

## 核心函数`ans()`

>这个函数主要用于运算`+ - * /`运算逻辑实现，使用了`switch-case`来写，用`if-else`结构也可以，这里需要注意的是除数不能为零的情况

```bash
double ans()
{
	printf("你输入的表达式是：%.2lf %c %.2lf\n", num1, op, num2); //输出用户输入的表达式
	while (1)
	{
		switch (op)  //加减乘除判断以及验证输入数值合法性
		{
		case'+':
			answer = num1 + num2;
			return answer;
			break;
		case'-':
			answer = num1 - num2;
			return answer;
			break;
		case'*':
			answer = num1 * num2;
			return answer;
			break;
		case'/':
			if (num2 == 0)
			{
				printf("\n错误:除数不能为零！\n");
				answer = 0;  //把answer变量赋值为0
				return answer;
				break;
			}
			else {
				return answer;
				break;
			}
		default:
			printf("\n错误:无效的运算符！\n");
			break;
		}
		printf("\n");
	}
}
```

## 函数主入口`main()`

>最后我们只需要在`main()`里调用函数即可

```bash
main()
{
	menu();  //调用界面函数

	answer_1();  //调用计算函数

	printf("\n");  //换行
}
```
