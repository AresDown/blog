## 引言

这次给大家推荐一个主要由python开发的电脑风扇控制中心，这个程序代替了外星人控制面板的一些功能
大多数在买到戴尔G系列笔记本后都会带这个控制中心!
{% imgf tcc/tcc.webp %}
但如果没有买外星人的笔记本，这个控制中心就有些功能的限制，并且该程序占用的空间也较大，界面有点臃肿，大部分功能可以被英伟达官方的GeForce或Nvidia app代替，如果对于电脑存储空间小的来说就显得有点占位置
{% imgf tcc/tcc7.webp %}
而且这个控制中心在后台运行也会比较吃RAM和CPU

## 程序介绍

因这些问题，在github上就有了一个AlexIII制作的tcc-g15，这个程序具备了温度控制和自定义风扇转速等功能，占用空间小，很好用
{% imgf tcc/tcc1.webp %}
{% imgf tcc/tcc2.webp %}
在作者的不断更新下，版本来到了v1.6.4并且也支持外星人控制面板的F9键G模式，不过程序唯一的缺点是不支持多语言，只有主流的英文版，观感不太好，所以我修改了程序的显示，改为了中文版
{% imgf tcc/tcc3.webp %}
{% imgf tcc/tcc4.webp %}
{% imgf tcc/tcc5.webp %}
{% imgf tcc/tcc6.webp %}
最后提供一个下载地址提供给需要的人
