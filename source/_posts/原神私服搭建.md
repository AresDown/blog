## 一. 所需工具

- 1.下载并安装Java17 [Java17](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html)
- 2.下载[mongodb](https://www.mongodb.com/try/download/community)数据库
- 3.获取服务器文件[LunaGC_5.3.0](https://github.com/Kei-Luna/LunaGC_5.3.0)
- 4.下载服务端资源包[5.3-res](https://github.com/pmagixc/5.3-res)
- 5.下载客户端
- 6.获取客户端补丁[hk4e-patch-universal](https://github.com/oureveryday/hk4e-patch-universal)

### `注意`

- 1.`LunaGC_5.3.0`仓库介绍中包含客户端下载链接
- 2.hk4e-patch-universal并未编译文件且设置端口与当前服务器端口不同
- 3.`客户端补丁`与`客户端`推荐访问我的[github](https://github.com/WorldDawnAres/hk4e-patch-universal)仓库获取

## 二.服务器搭建

**操作前需要先安装好Java17和mongodb数据库**
下载好服务端资源包和编译服务器文件后参考下图放置文件
{% imgf yuan/yuan1.webp %}
`5.3-res`的资源包下载后需要将文件夹重命名为`resources`，并将编译好的服务端`LunaGC-5.3.0.jar`与`LunaGC_5.3.0仓库`的`keystore.p12`文件一起放在一个文件夹内

然后执行如下代码运行来启动服务端

```bash
java -jar LunaGC-5.3.0.jar
```

启动成功后会显示如下内容
{% imgf yuan/yuan2.webp %}
此时服务端启动成功

我们再输入以下代码创建账号+uid或创建账号+密码+uid

```bash
account create <username> [<UID>] //第一种方式
account create <username> <password> [<UID>] //第二种方式
//例如
account create 123456 123456
//或
account create 123456 123456 100001
```

`如果选择第一种只创建账号+uid，需要进入客户端在密码栏随便输入密码进入游戏，且下次还使用这个账号的时候输入之前随便输入的密码`

**操作前需要先编译或下载客户端补丁**
下载好客户端补丁后参考下图放置补丁
{% imgf yuan/yuan8.webp %}

## 四.代理工具

目前我已知的有四种方式可以用来使本地服务端和客户端通信

- 1.`Fiddler`工具
- 2.`Cultivation`游戏启动器(`目前在更新且有5.4.0版本`)
- 3.`mitmproxy`工具
- 4.客户端补丁(当前教程使用的方法)

## 五.已知问题

`服务端功能并不完善，作者可能已经停止更新`

- 1.邮件功能无效
- 2.进行一些合成材料时会卡死
- 3.怪掉落的物品和获得的星魂无法使用
