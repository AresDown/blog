> 该程序是一个简单俄罗斯方块游戏，是之前博主课设做的程序，包含了一些简单功能
>

## 功能

- 开始游戏界面
- 添加了经典俄罗斯方块背景音乐
- 有简单登录界面
- 可以记录用户分数

## 安装和运行方式

### 安装python库

>使用以下命令安装所需的Python库:

```bash
pip install pygame sqlite3
pip install PyInstaller(可选)
```

### 运行程序

>你可以使用以下任一方式来运行程序：

#### 方法一

>使用 PyInstaller 打包程序：

```bash
PyInstaller -F --add-data "picture/*;picture" --add-data "fonts/*;fonts" -w -i game\picture\icon.jpg UI.py
```

>然后在 dist 目录下找到可执行文件。

#### 方法二

>直接运行 Python 脚本：

```bash
python UI.py
```
